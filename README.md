# Markandey Pandey Pustak Mandir · Multi-school website concepts

Open `website-samples.html` for the dedicated school website studio and gallery of thirty distinct concepts. Each `school-01.html` through `school-30.html` has its own name, sample photography and page composition. The original Cursor-created Aarohan demo remains available as `demo.html` when these files are copied to the GitHub repository.

The school concepts use intentionally different layouts: editorial, dark STEM dashboard, colourful bento, glass/orbit, heritage, nature-led, high-contrast, storybook, Nordic minimal and arts collage. Their section order, visual treatment and mobile layout vary. All include responsive navigation, searchable class resources, print-to-PDF, gallery, notices, Maps search, Hindi/English controls, dark/light mode and WhatsApp enquiry buttons.

## Keep the folder structure

All concepts carry Markandey Pandey Pustak Mandir attribution. Website development is offered at no cost to all MPPM customers.

For GitHub Pages, put `index.html`, `website-samples.html`, the thirty `school-*.html` pages, and `assets/` at the repository root. `assets/site.css`, `assets/layouts.css` and `assets/site.js` are shared by the pages. Keep the original `demo.html` alongside them if the original Cursor site is needed separately.
