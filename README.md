# Markandey Pandey Pustak Mandir · Multi-school website concepts

Open `index.html` for the showcase of ten school concepts. Each `school-01.html` through `school-10.html` has its own name, sample photography and page composition. The original Cursor-created Aarohan demo remains available as `demo.html` when these files are copied to the GitHub repository.

The school concepts use intentionally different layouts: editorial, dark STEM dashboard, colourful bento, glass/orbit, heritage, nature-led, high-contrast, storybook, Nordic minimal and arts collage. Their section order, visual treatment and mobile layout vary. All include responsive navigation, searchable class resources, print-to-PDF, gallery, notices, Maps search, Hindi/English controls, dark/light mode and WhatsApp enquiry buttons.

## Keep the folder structure

For GitHub Pages, put `index.html`, the ten `school-*.html` pages, and `assets/` at the repository root. `assets/site.css`, `assets/layouts.css` and `assets/site.js` are shared by the pages. Keep the original `demo.html` alongside them if you want the original Cursor site linked in the gallery.

The three supplied publisher catalogues (Magic Mind, Galaxy Publication and Coral Publication) are included under assets/catalogs and linked from store.html. The multi-class builder uses legible class rates transcribed from those 2026–27 PDFs; unclear combinations say “Check catalogue.” Confirm rates and editions before orders. School names, locations, notices, statistics, principal portraits and school photographs remain illustrative samples.
