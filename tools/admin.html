Manage the school details

This editor runs on this computer. It saves plain project files and rebuilds each school's public page. There is no database. Keep a backup when editing.

School profile information is published with the website. Do not enter private student or family data here. To add school photos, place approved image files in assets/schools/ and set their relative paths in the matching photo fields.
